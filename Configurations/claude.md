# Arbeitsregeln

- **Tests:** Nach Edits die Tests laufen lassen, wenn es welche gibt.

- **Keine Commits:** Keine `git commit`, außer explizit verlangt.
- **Allow-List:** Befehle so formulieren, dass sie von der Permission-Allow-List gedeckt sind (kein unnötiges Verketten mit `&&`/`;`/Loops).
